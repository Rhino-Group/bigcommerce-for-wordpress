# AGENTS.md — BigCommerce for WordPress (Suma)

## Project Overview

A WordPress plugin that powers an e-commerce storefront backed by BigCommerce. Products, cart, checkout, accounts, reviews, and currency management are all rendered through PHP templates in `templates/public/`.

---

## Key Architecture

| Layer | Location |
|---|---|
| Plugin bootstrap | `bigcommerce.php` |
| PHP source classes | `src/BigCommerce/` |
| Public templates | `templates/public/` |
| Admin templates | `templates/admin/` |
| CSS assets | `assets/css/` |
| JS assets | `assets/js/dist/` |
| Vendor dependencies | `vendor/` (Composer) |

---

## Coding Standards

- **PHP**: WordPress Coding Standards + PSR-4 autoloading via Composer
- **CSS**: Generated by Grunt from `pcss/` source files — edit `assets/css/bc-accessibility.css` for accessibility override styles; **do not** edit `master.css` or `master.min.css` directly
- **JS**: `assets/js/dist/` is compiled; edit source files if a build pipeline is available
- **Templates**: Override-friendly — themes place overrides in `[theme]/bigcommerce/`

---

## Template Variable Pattern

Templates receive variables via PHP `extract()`. Variables are documented in the file docblock `@var` tags at the top of each template.

## Skip Link

To achieve full WCAG 2.4.1 (Bypass Blocks) compliance, the active theme must render:

```html
<a href="#main" class="bc-skip-link">Skip to main content</a>
```

as the **first focusable element** inside `<body>` before the site header. The plugin provides the CSS (`.bc-skip-link` in `bc-accessibility.css`) but the theme controls the `<header>` output.
